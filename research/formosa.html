ForMoSA

Forward Modeling tool for Spectral Analysis

GitHub Repository Read the Docs arXiv Paper ADS Publication Library

Open source & community-driven

ForMoSA is an open-source Python package developed to fit spectroscopic and photometric observations using a Bayesian framework. It enables robust parameter space exploration by utilizing several state-of-the-art self-consistent atmospheric models.

Since its release, ForMoSA has been adopted widely by exoplanet researchers for the atmospheric retrieval of young planetary-mass brown dwarfs and directly imaged exoplanets. A list of scientific papers using ForMoSA for spectral analysis is maintained in the ADS Publication Library.

Development team & collaboration

The code is developed and maintained by a growing international collaboration of developers including S. Petrus, P. Palma-Bifani, M. Ravet, A. Denis, B. Rajpoot, M. Bonnefoy, G. Chauvin, A. Vigan, A. Radcliffe, P. Requeijo, and K. Hoy at institutes across the globe:

  • IPAG (Grenoble, France)
  • LIRA / Obs. de Paris (Paris, France)
  • LAM (Marseille, France)
  • Laboratoire Lagrange (Nice, France)
  • MPIA (Heidelberg, Germany)
  • NASA Goddard Space Flight Center (USA)
  • Universidad Diego Portales (Santiago, Chile)

We are always open to new collaborations! If you are interested in using ForMoSA for your research, introducing new features, or integrating new grids, please do not hesitate to reach out or contribute directly on GitHub.
